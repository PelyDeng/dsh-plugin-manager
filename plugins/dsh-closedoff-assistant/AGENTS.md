# dsh-closedoff-assistant 开发约定

本插件的业务实现和开发资源由本目录维护。通用元数据与发布规范遵循仓库根 AGENTS.md。私有源码更新使用仓库根 `build.sh` 或 `build.ps1`，由 `private-deploy/` 更新 Gitee 源码并调用公共构建；底层安装、启动和部署命令位于根 `deploy/`。

## 三维地图与模型校高

- 浏览器三维能力优先使用公开发布的 CesiumJS；只有公开 API 明确无法满足并有可复现证据时，才引入私有 GIS 封装包。
- 地形与 3D Tiles 的高程基准可能不同。tileset 加载后必须先按部署配置沿椭球法向设置 `modelMatrix` 高度偏移，再执行相机取景；不得通过关闭 `depthTestAgainstTerrain` 掩盖穿模。
- 模型高度属于数据集配置，不能照搬其他园区的数值。轨迹视图按轨迹、起终点和已筛选设备组自动取景；更换地形或 tileset 地址后，应在多个控制点检查贴地、穿模、悬浮和相机范围。
- 三维依赖版本、模型配置字段或 Bundle 配置变化后重启插件服务；普通页面样式与交互改动继续使用开发模式热加载。
- 问答正文中的轨迹必须自动生成静态三维场景截图，生成后立即销毁临时 Viewer；多条轨迹的截图必须串行生成。“截图并保存”只放在“全屏查看”的三维弹窗中，保存当前视角为本机 PNG 时不得销毁或改变弹窗 Viewer。
- 设备组按点到轨迹线段的最短距离筛选，距离阈值属于部署配置。默认值只适用于当前园区，调整后应使用真实轨迹检查相邻道路误入和轨迹附近点位漏出。
