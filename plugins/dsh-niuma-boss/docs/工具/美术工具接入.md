# PixelLab、Pixelorama 与 Tiled 接入

PixelLab 生成素材，Pixelorama 修整像素与逐帧动画，Tiled 组装地图。统一配置位于本插件根目录的 [art-tools.config.json](../../art-tools.config.json)。

## 配置内容

| 字段 | 用途 |
| --- | --- |
| `pixellab.apiKey` | PixelLab API Key |
| `pixellab.mcpUrl` | 官方 MCP 地址 `https://api.pixellab.ai/mcp` |
| `pixellab.generationBudgetUsd` | 首批生成费用上限，目前为 5 美元，不含订阅和软件购买 |
| `pixelorama.executablePath` | Pixelorama 可执行文件的绝对路径 |
| `tiled.executablePath` | Tiled 可执行文件的绝对路径 |

按客户明确要求，真实 API Key 随配置提交到本私有 Gitee 仓库；这是仅针对该配置的授权例外。仓库读取者可取得并使用它，不将该配置复制到公共 GitHub、公开示例或生成素材中。文档和校验输出不重复密钥值。

预算字段记录本次授权上限，不是服务商账户的自动扣费限制。生成前核对余额和估价，每次记录任务 ID 与实际费用；累计不得超过 5 美元。计费口径不明或需另购订阅时，先停止付费请求。

## 加载 PixelLab 配置

从仓库根目录打开 PowerShell，读取配置并将 Key 提供给 MCP。配置值通过环境变量传递，不作为命令参数打印：

```powershell
$artConfigPath = Join-Path (Get-Location) 'plugins/dsh-niuma-boss/art-tools.config.json'
$artConfig = Get-Content -LiteralPath $artConfigPath -Raw | ConvertFrom-Json
if ([string]::IsNullOrWhiteSpace($artConfig.pixellab.apiKey)) {
    throw 'PixelLab API Key 未配置。'
}
[Environment]::SetEnvironmentVariable('PIXELLAB_API_KEY', $artConfig.pixellab.apiKey, 'User')
[Environment]::SetEnvironmentVariable('PIXELLAB_API_KEY', $artConfig.pixellab.apiKey, 'Process')
codex mcp add pixellab --url $artConfig.pixellab.mcpUrl --bearer-token-env-var PIXELLAB_API_KEY
Remove-Variable artConfig
codex mcp get pixellab --json
```

如果已有同名 MCP，先用 `codex mcp get pixellab --json` 检查；地址和环境变量名称一致时沿用即可。改 Key 后重新运行环境变量加载步骤，避免 Windows 用户变量仍使用旧值。当前应用若尚未读到新环境变量或工具列表，重新打开应用后检查 MCP 状态。

先核验工具列表与 `get_balance`，再开始素材生成。美元余额和订阅次数分别核对，不能直接把次数当成美元。这里只使用素材能力，不开启 PixelLab 的应用开发或部署功能。官方说明见 [PixelLab MCP 文档](https://api.pixellab.ai/mcp/docs)。

## 本机编辑器

已核验以下可执行文件存在，版本来自文件元数据；尚未进行 GUI 操作验收。路径以配置文件为准，换电脑时更新对应字段。

| 工具 | 当前路径 | 文件版本 |
| --- | --- | --- |
| Pixelorama | `E:\B_其他工具\Pixelorama素材修复\Pixelorama-Windows-64bit\Pixelorama.exe` | 1.2.2.0 |
| Tiled | `E:\B_其他工具\Tiled地图组装\tiled.exe` | 1.12.2 |

[Pixelorama](https://pixelorama.org/) 免费开源，负责逐帧修整和导出，保留 `.pxo` 可编辑源文件；当前工作流不需要购买 Aseprite。[Tiled](https://www.mapeditor.org/) 负责地图组装，保留地图与瓦片集源文件。PixelLab 通过 MCP 生成，不依赖这两个编辑器安装 PixelLab 扩展。

生成图、候选预览、精修源文件和 Tiled 小样先保存到仓库 `.local/dsh-niuma-boss/art/`。配置完成不代表素材或地图已经通过验收。
