# 独立游戏插件与共享管家任务

状态：已采纳。用户于 2026-09-13 确认。

游戏以 `dsh-niuma-boss` 独立插件运行；现有 `dsh-butler-console` 群聊插件由同事继续维护。游戏优先通过明确接口复用现有管家的理解、调度、结果收集及任务管理能力，避免形成两套调度实现和相互冲突的任务记录。

同一可信用户在游戏和群聊中使用同一份业务任务与历史：游戏发起的任务可在群聊中查看和继续处理，群聊中的任务也可由游戏展示并在能力与权限允许时继续处理。切换入口不创建任务副本，不改变任务归属；来自任一入口的操作均需经过相同的授权、任务状态及幂等校验。

游戏独立管理地图、人物、镜头、动画、岗位活动及其它表现状态；管家管理业务任务的权威状态。人物演出不推进业务终态。共享任务与历史不代表合并每个员工或普通 NPC 的独立对白会话，也不改变角色原有能力。

初期可由现有管家插件提供对外接口；是否以后提取共享模块、采用哪种通信方式、接口版本和缺失能力如何处理，留待第四阶段后续设计。本次决定不要求修改同事正在完善的实现，也未授权复制其私有源码、直接共享写入数据库或跨用户访问任务。

当前 `butler/executors` 是员工执行入口登记契约，不能当作完整的管家任务管理接口。后续需核实并约定任务提交、查询、回复、取消、历史与状态订阅接口，以及双入口并发修改、重连和恢复行为；记录本决定不表示这些运行路径已经实现或验收。
