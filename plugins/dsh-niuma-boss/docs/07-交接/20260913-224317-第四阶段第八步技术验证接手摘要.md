## 关键决定

1. 使用 `Phaser 4.2.1` 负责地图、人物、镜头、动画与输入；使用 Vue 3 + Pinia 负责 DOM 任务本、对话框、HUD 和中文输入。
2. 前端用 Vite + TypeScript + Vue SFC，后端入口沿用 `tsdown`；不使用 CDN、Nuxt、SSR、Router 或 Pinia 持久化插件。
3. 移动使用碰撞网格；键盘连续移动，鼠标/触摸点击后 A* 自动绕障。寻路采用 `easystarjs@0.4.4`，四邻格、曼哈顿距离、禁止斜走，最多展开 4096 节点，单帧预算 2 ms。
4. 图集构建采用 `free-tex-packer-core@0.3.9`，禁止旋转与裁边，单张不超过 2048×2048。地图同时读取 `.tmj/.tsj` 与 `*.layout.json`，由最小 Node 脚本交叉校验后输出单份运行时 JSON。
5. 浏览器直接调用同源管家 HTTP/SSE，`ButlerClient` 是唯一网络接缝；不代理任务、不复制正文、不访问管家数据库。
6. 运行模块只有 `PluginServer`、`ButlerClient`、`GameSession`、`GameWorld`、`GameUI`。`GameSession` 是核心深模块；`web/main.ts` 只组装。
7. 首版不建游戏服务端数据库。`localStorage` 按登录身份只保存地图、合法格子、朝向和少量偏好；不保存任务正文或凭据。换设备从安全出生点开始，任务仍由管家共享。
8. 管家断线或无权限时允许地图浏览和普通 NPC 预写对白，任务写操作禁用。读订阅按 1/2/5/10 秒退避重连；`reset` 后读权威快照。写请求只有响应未知时才以相同正文和原 `requestId` 重试；`409`、权限、版本冲突、`run_result_unknown` 与 `/stop` 不自动重试。
9. 桌面目标 60 FPS/p95 20 ms，移动端最低 30 FPS/p95 33 ms；办公楼 11 人、特效与 SSE 同时运行作为重场景。Vue 不接收逐帧坐标，后台暂停 Phaser，回前台恢复任务快照和订阅。
