# 像素素材工具官方核验

核验日期：2026-09-13。范围：官方公开文档与官方 GitHub；未安装、购买、生成或实测画质。

- 建议先试 PixelLab 作为主制作链。v3 能从南向参考 sprite 生成 8 向，Pro 可用既有角色 ID 统一新角色风格，再给保存的角色增加动画；32px 顶视连通 tileset、地图物件及 building kit 可覆盖办公楼和咖啡店。该建议来自工作流匹配，不能据此判断实测画质。来源：[MCP 文档](https://api.pixellab.ai/mcp/docs)、[建筑和图块工具](https://www.pixellab.ai/docs/tools/create-tiles-pro)。
- Retro Diffusion 是可比较的备选：RD Pro 最多 9 张参考图；原生四向 walk/idle 模型固定 48×48；起始帧动画支持 32–256px，并可输出 PNG spritesheet；Wang tileset 支持 16–32px。来源：[官方 API 示例与限制](https://github.com/Retro-Diffusion/api-examples)。
- 两家均有官方 API 与远程 MCP：PixelLab 为 `https://api.pixellab.ai/mcp`；Retro Diffusion 为 `https://mcp.retrodiffusion.ai/mcp`。后者的官方 MCP 提供免费成本预估和自定义风格工具。来源：[PixelLab 接入方式](https://www.pixellab.ai/docs/ways-to-use-pixellab)、[Retro Diffusion MCP](https://github.com/Retro-Diffusion/retro-diffusion-mcp)。
- 价格入口：PixelLab 官方 API 估价中，32px 顶视 tileset $0.0099，64px v3 角色 $0.041，64px v3 四帧角色动画 $0.0129/方向，GPU 时间会影响金额；不能把 API 美元估价直接当作订阅内 generations 的价格。Retro Diffusion 预付、无订阅、余额不过期；RD Pro $0.18/图，常规起始帧动画 $0.14，自定义动作 $0.25，tileset $0.10；实际以免费 `check_cost` 为准。来源：[PixelLab API 价目](https://www.pixellab.ai/pixellab-api)、[Retro Diffusion 价目](https://github.com/Retro-Diffusion/api-examples#pricing)、[预付规则](https://github.com/Retro-Diffusion/retro-diffusion-mcp)。PixelLab 订阅套餐月价未从本次可读页面核实，不填写推测金额。
- 32×48 角色格需要样张验收：PixelLab v3 参考模式默认沿用参考图尺寸，但 Pro 使用共享方形画布；Retro 四向预设是 48×48，不能直接当作本项目 32×48 帧格。应先验证牛马大总管的四向识别、脚点位置、动作边界、循环衔接及场景比例，再批量制作。PixelLab Pro 图块的风格参考只用于普通 Tiles，不用于连通集合，这一限制不能省略。来源：[PixelLab MCP 尺寸规则](https://api.pixellab.ai/mcp/docs)、[PixelLab Pro 图块限制](https://www.pixellab.ai/docs/tools/create-tiles-pro)、[Retro 动画规则](https://github.com/Retro-Diffusion/api-examples#animations)。
