> 本文档为结构化需求描述，供 AI 理解项目目标、玩法、角色、场景、美术风格与技术原则。

## 一、项目一句话

基于 **DeepSeek Harness** 构建一个 **多 Agent 像素风职场模拟游戏**。玩家扮演“老板”，用方向键控制老板角色在俯视办公楼中移动，只与“牛马大总管 Agent”对话发任务；牛马大总管负责任务拆解、调度 3 个普通 Agent，子 Agent 会在地图中自动寻路过来回答或执行。整体画风俏皮、搞抽象、搞笑，拒绝传统商务严肃风。

---

## 二、背景与主题

- **现实背景**：开发者是苦逼程序员，天天被领导压榨。
- **游戏内反转**：在游戏里当老板，自己控制方向键移动，给 Agent 发任务，体验“翻身做主”的爽感。
- **氛围基调**：轻松、幽默、搞抽象、活跃气氛。办公场景要有趣，角色表情和动画可以夸张、俏皮。
- **视觉主题**：现代职场办公楼俯视视角，高精美像素风，但不是廉价复古，也不是传统商务风。

---

## 三、核心体验

- **玩家即老板**：用键盘方向键控制老板角色在办公楼内移动。
- **统一入口**：所有任务只对牛马大总管 Agent 说。
- **牛马大总管调度**：牛马大总管负责任务理解、拆解、优先级排序、分发、跟踪、汇总、异常处理。
- **角色可见**：子 Agent 不是后台接口，而是地图上会移动、会等待、会做动作的像素角色。
- **世界活着**：没有任务时，Agent 自主巡逻、待机、去兴趣点、彼此互动。
- **实时反馈**：通过气泡、对话框、任务面板、状态面板实时展示任务进展。
- **成功标准**：老板一句话，牛马大总管正确调度，子 Agent 自动跑过来回答，整体体验像游戏一样流畅自然。

---

## 四、角色与职责

| 角色 | 职责                                                                                   | 控制方式            |
| ------ | ---------------------------------------------------------------------------------------- | --------------------- |
| **老板（玩家）**     | 游戏内玩家化身，可在办公楼中移动，与牛马大总管 Agent 对话发任务                              | 键盘方向键控制移动  |
| **牛马大总管 Agent**     | 用户唯一入口；任务理解、拆解、路由、调度、汇总、异常处理                               | AI 自主，玩家可对话 |
| **普通 Agent A/B/C**     | 各自拥有独立能力、性格、外观和动画；无任务时自主活动；被调度后寻路到目标位置执行并回答 | AI 自主             |
| **NPC（后期）**     | 移动 NPC、固定点位 NPC（如咖啡厅 NPC 等），用于丰富世界                                | AI 或脚本控制       |
| **游戏世界**     | 提供地图、寻路、碰撞、动画、光照、UI、事件触发等表现层能力                             | 系统                |

## 五、地图与场景

### 第一版地图：现代职场办公楼（俯视视角）

- **整体**：一栋办公楼的俯视平面，像素风，房间分明，可走道连接。
- **房间示例**：

  - 老板办公室
  - 开发部
  - 市场部
  - 公共区（茶水间、休息区等）
- **表现**：每个房间有家具、设备、装饰，风格俏皮搞怪，比如夸张的电脑、搞笑的绿植、抽象的海报。
- **角色**：牛马大总管 Agent + 3 个普通 Agent，共 4 个可自主移动的像素角色；老板角色由玩家控制。

### 后续扩展场景

- 走出办公楼：街道、其他建筑物。
- 建筑物示例：咖啡厅、网吧、服装店、小吃街。
- NPC 扩展：

  - 移动 NPC
  - 固定点位 NPC（如咖啡厅 NPC）
- 地图扩展原则：数据驱动或插件化，便于增加新地图、新房间、新交互点。

## 六、美术风格与氛围

- **风格**：高精美像素风，俏皮、搞抽象、搞笑，活跃气氛。
- **画面要素**：统一色调、动态光照、阴影、粒子、天气、角色帧动画、场景层次、Y-Sort。
- **像素规范**：像素完美、整数倍缩放、UI 清晰；地图 tile 与角色尺寸统一。
- **角色设计**：表情夸张、动作幽默，可加入搞怪待机动画、吐槽气泡。
- **UI**：对话栏、任务面板、Agent 状态、气泡、寻路指示、交互提示等。风格与像素世界统一，同时保证可读性，可加入搞笑元素。
- **目标观感**：角色自主生活，像一个小型职场喜剧现场，而不是静态立绘或纯聊天窗口。

---

## 七、典型交互流程

1. 玩家用方向键控制老板角色在办公楼中移动。
2. 老板靠近牛马大总管 Agent 或通过快捷键打开对话，输入任务或问题。
3. 牛马大总管 Agent 解析意图，拆解任务，决定调用哪个或哪些子 Agent。
4. 被调度的子 Agent 在地图中自动寻路到牛马大总管或老板附近。
5. 子 Agent 播放到达、思考、回答等动画，并通过气泡或对话面板输出内容。
6. 牛马大总管 Agent 收集结果，必要时继续追问子 Agent，最后统一回复老板。
7. 未参与任务的 Agent 继续自主活动，保持世界“活着”的感觉。

---

## 八、游戏机制与系统

- **移动与寻路**：A\* 或导航网格，支持多角色同时寻路、避障、到达后状态切换。
- **行为状态机**：Idle、Patrol、GoTo、Work、Report、Return 等。
- **任务系统**：牛马大总管解析 → 拆解 → 分发 → 子 Agent 执行 → 汇总 → 回复。
- **对话系统**：气泡、对话框、流式文本输出。
- **自主活动**：无任务时，Agent 巡逻、待机、去兴趣点、彼此互动。
- **事件总线**：任务状态、对话内容、角色动作实时同步到表现层。
- **交互提示**：靠近可交互对象时显示提示，支持老板与 Agent、NPC 互动。

---

## 九、技术架构原则

- **推理与表现分离**：DeepSeek Harness 负责推理、工具调用、记忆和任务编排；游戏层负责移动、动画、碰撞、UI 和音效。
- **通信方案**：事件总线 / WebSocket / SSE / 本地进程通信，保证流式文本和任务状态实时同步。
- **前端引擎**：Phaser 4（已确定），原生 Web，像素风支持好，AI Agent 集成度高。
- **Agent 运行时**：DeepSeek Harness，优先原生插件/Skill。
- **数据驱动**：地图、角色、Agent 类型、技能/工具、任务模板、对话配置、事件触发器尽量数据驱动或插件化。
- **性能目标**：优先 60 FPS，低端设备尽量 30 FPS；AI 请求不能阻塞游戏主循环。
- **优化方向**：纹理图集、对象池、分块地图、视锥裁剪、异步加载、流式输出、按需渲染。

---

## 十、扩展规划

- **地图扩展**：办公楼 → 街道 → 咖啡厅、网吧、服装店、小吃街等。
- **角色扩展**：增加更多普通 Agent、NPC（移动/固定点位）。
- **Agent 能力扩展**：新技能、新工具、新任务模板。
- **交互扩展**：更多事件触发器、对话分支、小游戏或彩蛋。
- **世界观扩展**：保持俏皮搞怪基调，可加入更多职场梗、抽象幽默。

---

## 十一、成功标准

- 老板可以用方向键自由移动。
- 老板只与牛马大总管对话，牛马大总管正确调度子 Agent。
- 子 Agent 自动寻路过来回答，动画和气泡表现自然。
- 未参与任务的 Agent 保持自主活动，世界“活着”。
- 整体画风俏皮、搞抽象、搞笑，不严肃、不商务。
- 后续地图、角色、NPC 可方便扩展。
- 运行流畅，优先 60 FPS。
