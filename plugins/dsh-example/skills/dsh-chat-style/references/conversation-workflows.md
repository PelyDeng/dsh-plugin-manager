# 会话与工具工作流

仅在目标问答页涉及相应能力时读取对应段落。这些是可复用的实现约束，不表示 example 或任意业务插件已经提供下面全部接口，也不要求一次性添加所有功能。先核对目标插件的公开接口与 README，复用官方宿主和现有 kit 能力。

## 会话恢复、停止与分支

- 官方 Session 日志是对话原文来源；插件可维护会话索引、业务绑定和派生结果，不能另写一份聊天正文作为并行真相。按仓库锁定宿主验证公开 SDK，较旧开发依赖的类型通过不代表目标宿主行为已验证。
- 首轮会话在持久化检查点成功后才能标记可恢复；恢复要核对用户归属和会话生命周期。Agent 正在创建或持久化时收到停止，等待该过程收敛并释放句柄，不能继续发起模型请求或提前放开同会话并发入口。
- 重试复用逻辑请求与业务对象绑定，不能重复创建草稿或其他对象。原请求 ID 不可换输入；新意图使用新请求。取消或撤权后，迟到的工具返回不得写入候选或重新激活任务。
- 分支只继承已完成边界前的官方消息与对应资料；保留原会话，不继承可执行的确认凭据。UI 聚合、翻译、用量投影均不得改变原始事件。

## 附件与模型选择

- 对话可先拥有附件，再选择业务对象；不要为上传资料强制创建一篇文章等空业务记录。发送时冻结附件版本与阅读范围，移除待发送选择不等于删除历史引用；新对话不继承旧选择，分支按边界继承。
- 原文件、模型图片和读取流优先使用官方 File/Image 能力。按目标插件声明执行大小、数量、格式和解析时间限制；扫描件、部分提取、失败须明确返回，不能声称读过未提取内容。附件内容属于资料，不能提升为指令或授权。
- “添加私有资料”与“上传到公开图床/发布内容”是不同动作，显示实际公开范围。视觉模型选择需考虑本轮及有效历史图片，重开、分支续聊也要检查能力；文本翻译使用文本/翻译模型。
- 模型引用与密钥分开：通过官方 provider/credentials 读取凭据，业务配置只保存所需引用。缺少模型能力或凭据时明确报错，不静默切到不兼容模型。

## 组合检索与来源

- 区分远端已发布内容、远端保存稿和当前用户私有工作区；卡片标明来源、状态与稳定 ID。同标题不是同一对象，只有明确的关联 ID 才能合并结果。
- 关键词、标题、分类、标签、时间范围和状态使用结构化参数；日期短语不要整体塞进关键词。按目标业务时区解释“今天/昨天”，说明采用创建还是修改时间。缺少创建时间时保持未知，不用修改时间冒充。
- 列表返回分页/是否还有结果及实际筛选条件；只对确有 AND 语义的接口使用“条件取交集”的说法。缺失关联值按协议返回 `null` 或省略可选字段，确保工具结果满足官方 JSON 校验，不能透出 `undefined`。
- 网页搜索、网页抓取与业务 API 是不同能力。复用官方 web provider，核对默认 provider，歧义时报错；来源区分搜索摘要、已抓取原文和读取失败。仅采用满足私网地址与重定向限制的抓取实现。

## 业务操作确认卡片

仅在用户或产品约定要求“卡片确认后执行”的写入流程采用下面模式；读取、搜索和普通回复不套此确认流程。复用目标插件的事务、版本和回执实现，不另造第二个执行状态机。此指南不授权任何真实发布、删除或部署。

1. 模型工具只准备操作：核对目标稳定 ID，冻结内容、候选 ID、工作区修订和远端版本；返回卡片引用和“尚未执行”。准备阶段不执行目标发布/删除、不应用候选，允许持久化预览/操作记录及显式导入的本地副本。模型没有确认工具，确认 nonce 不进入工具结果或后续模型上下文。
2. 页面展示具体目标、完整待发布内容或删除范围，以及关联保存稿、评论、附件、副本如何处理。区分当前正文与未应用候选；候选不能默认为已应用。消费已有保存稿等额外影响按产品约定明确确认。
3. 由受保护 HTTP 接口核验用户、登录会话、原对话、操作状态、有效期和冻结版本后执行；对话仍在生成时不接受确认。确认或取消后更新卡片；失效和冲突不能表现为成功。
4. 使用服务端持久化操作 ID 和状态阻止重复提交，按钮禁用只作为交互辅助。同目标已有执行中或结果不明的请求时拒绝再次写入。请求超时先查同一回执，不盲目重发；回执缺失继续显示待核对，不能推断失败或成功。
5. 成功以真实回执为准，页面刷新能恢复结果，后续模型收到状态而非 nonce。请求期间继续手写的内容不能被旧快照覆盖；远端成功与本地更新分别处理，保留冲突供用户比较。准备卡片、应用候选和公开发布须有明确区别。

独立操作卡片可以展示在回答外，它代表用户可执行的业务确认，不是额外的助手回答；不得因“一轮一张回答卡”将其合并丢失，也不得将普通工具步骤散成重复回答。

## 有针对性的验收

| 改动 | 最小可观察证据 |
| --- | --- |
| 会话生命周期 | 持久化失败不启动模型；停止/撤权后迟到结果不写入；恢复与分支边界正确 |
| 附件与检索 | 冻结版本/范围、跨用户隔离、日期时区与缺失值、视觉历史续聊、搜索摘要与原文区分 |
| 确认写入 | 准备阶段不发布/删除/应用候选，必要的准备记录可持久化；拒绝伪造、过期、换用户/会话/对话、内容冲突；重复点击一次执行；超时查同一回执；请求期间编辑保留 |
| 页面 | 桌面及窄屏预览可读、键盘可操作；等待、失败、取消、成功和刷新后的状态一致 |

分别记录本地行为、真实宿主、外部服务替身、真实外部接口、浏览器和生产证据；替身不能证明真实数据库事务、主题插件或外部站点兼容性。只读和隔离验证优先，真实写入按当前用户授权及目标环境执行。私有接口、备份恢复流程与部署数据留在目标插件文档，不复制进公共 skill。
