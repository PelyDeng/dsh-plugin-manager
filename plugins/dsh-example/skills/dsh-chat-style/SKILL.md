# DSH 聊天页面风格

## 依据与范围

当工作区可读取 `plugins/dsh-closedoff-assistant/web/app.css`、`app.js`、`index.html` 时，**封闭化当前代码是最终样式依据，截图只用于辅助对照**。先读取通用聊天部分，核对现有公共基线；不得凭截图猜测并覆盖可从代码获得的数值。

公共仓库与独立插件不依赖私有插件。已落地的通用基线是本 skill 相对路径：

- [chat-base.css](../../web/chat-base.css)：配色、字体、气泡、思考区、工具状态、回答工具栏、Markdown、窄屏规则。
- [style.css](../../web/style.css)、[index.html](../../web/index.html)：顶栏、聊天列、右侧快捷问题、底部输入、桌面历史侧栏与手机历史抽屉。
- [chat-ui.js](../../web/chat-ui.js)、[app.js](../../web/app.js)：真实操作和流式视图。
- [官方图标与许可](../../web/media/LICENSE.txt)：使用已有资源，不自行绘制近似图标。

只移植通用聊天部分。保留目标插件的名称、权限、路由、上传、编辑等业务入口。三维场景、视频播放器、园区业务结果卡片、客户文案和私有配置不进入公共框架或其他业务插件。

本 skill 是开发复用指南，不是模型运行时的业务授权。先查看目标插件当前源码、README 与宿主锁定版本；不能把其他插件已实现的能力当作目标插件现有能力。涉及会话恢复、附件、组合检索或发布/删除类确认时，再读 [会话与工具工作流](references/conversation-workflows.md)。纯视觉修改不要求增加这些能力；业务字段、接口与部署细节以目标插件文档为准。

## 视觉基线

- 字体按 PingFang SC、Microsoft YaHei、Segoe UI、system-ui 回退；正文 14px / 1.75，辅助文字 12–13px。不要把桌面整体缩放当作手机适配。
- 背景 `#f4f6fc`、辅助背景 `#f7f9fd`、面板白色、边框 `#e3e8f3`；正文 `#2b3445`、次要文字 `#5e6b7e`、强调 `#2457d6` / `#2f6fe4`。背景及蓝色气泡的渐变以来源代码为准。
- 白色顶栏，品牌在左，账号、历史、新对话、状态在右；主聊天列最大 1180px，桌面右侧 262px 快捷问题区。辅助业务区域允许按需抽屉呈现。
- 用户头像与蓝色气泡靠右，助手头像与白色卡片靠左。助手卡片边框 1px，圆角 `4px 14px 14px 14px`，内边距 `12px 15px`。
- 输入区在独立白色底栏，输入框圆角 12px，发送/停止按钮 44px。输入增高有上限，不遮住回复和手机安全区域。
- 手机收起右侧辅助区，历史从按钮打开；主要控件可触达、长表格/代码只在内容内部横向滚动。

历史导航复用 [conversation-history.js](../../web/conversation-history.js)：桌面默认展开，允许记忆收起状态，手机使用原生 modal 抽屉。支持标题搜索、按最近活动分组、当前会话高亮、逐项重命名/置顶/分享正文/多选删除。搜索与分页响应要丢弃过期版本；确认删除前说明实际范围；分享默认只复制或下载问答 Markdown，不生成公开访问。接口必须按当前用户检查每个目标。example 删除会话复用 kit 的移除流程，逐项移除插件历史入口并调用官方归档；部分失败不能报告为全部成功，应引导用户到会话管理中核实并重试。归档不永久销毁官方日志，也不删除博客文章等业务记录。用户头像在用户气泡右侧。

历史长标题在文本控件内单行省略，文字区域允许收缩（`flex: 1; min-width: 0`），更多操作按钮保持可见和固定宽度。将省略样式应用到实际文字盒，不能只给外层加 overflow；测试长中文标题、连续英文、当前项与键盘聚焦，不通过缩小字号或裁掉整行按钮解决。

## 流式与回答结构

同一用户提问只展示一张助手回答卡片，思考、工具调用和最终回答在卡片内清楚分区。工具状态使用横向列表并自动换行，不为每个工具或模型步骤新增外部消息卡片；流式输出持续更新当前卡片，历史回放保持同样的聚合方式。聚合只改变展示，保留官方事件、精确思考来源及最终回答反馈目标，整轮用量不重复累计。思考默认折叠，标题后保留分隔点和单行预览：流式、完成与历史始终显示最新非空行，长行裁去开头并保留最新末尾；不反转文字方向，展开后隐藏预览并显示完整文本。

复用 `chat-ui.js` 的 `thinking` / `updateThinking`；内部最大高度 320px，流式更新保留用户的折叠状态和内部阅读位置。没有真实 reasoning 时不编造预览。通过官方 systemPrompt.section 在其他业务/知识段之后注册独立语言段，明确工具调用前后的 reasoning_content 使用简体中文，回答默认中文、用户指定时可用其他语言；代码及必要原文保留；可配合官方运行上下文传递当前界面语言，快照使用插件来源并在聊天投影中排除，不拼入用户消息。快照会增加少量模型输入和审计记录，宿主关闭运行上下文时不生效。前端不伪造翻译或修改历史原文。

提示约束不能保证模型原始思考的语言。需要中文补救时复用 web/thinking-translation.js 和 src/reasoning-translation.ts：已保存的英语思考进入视口后，调用独立鉴权接口生成明确标记的“中文译文”，原文可展开。只按真实消息 ID 或持久化 attempt 序号读取原文，不用最终回答 ID 猜测前一步思考。

原始流必须存于独立状态，禁止把译文 DOM 作为 reasoning-delta 的累加器。只翻译持久化部分；中断原文需标注。译文用量、耗时单独展示；失败可重试；切换会话时取消，缓存命中仍检查归属和权限。通过官方 ctx.llm 调用当前模型，禁止创建伪用户消息、调用工具、重写原会话；单独的插件派生缓存随数据备份。

译文渲染遵循以下规则；源码工作区可额外查看 `plugins/dsh-example/src/reasoning-translation.ts`，安装归档不包含该源码，直接按本段复用。要求纯文本输出，但仅对已知的单字段 `{ "original": "译文" }` 包装（可带完整 JSON 围栏）解包一次；不递归解包，不泛化解析正常正文、代码或多字段 JSON。明确的损坏包装报错并保留原文。旧缓存走同一规范化入口，新结果标记已规范化，避免二次处理；修复渲染不重写官方日志。选用目标插件指定的文本/翻译模型，不能因为原对话有图片就自动换成视觉模型。

工具显示真实的执行中、成功、失败，不能把失败视为无结果。

工具卡片标题使用简洁中文显示名，英文 `name` 保持稳定作为调用编码，放在展开详情中；搜索兼容中文、编码、描述及参数。已有中文名优先复用，没有时按“动作＋对象”补齐，不用翻译后的名称替换调用协议。通过 kit 的 `createPluginTools().register(definition, displayName)` 提供目录元数据；第三方缺少显示名时回退编码，不编造含义。普通工具完成与业务提交成功分别呈现，例如“准备发布完成”只表示确认卡片已生成。

等待、思考、正文生成、停止、失败、完成都应可区分。正在生成时提供停止入口；停止后保留已有内容。尊重 reduced-motion。

用户已经上滚阅读时，新增内容不能把页面拉回底部；用户接近底部时才跟随。更新 DOM 前保存跟随判断，避免长增量导致跟随失效。不要反复替换整个消息区域或丢失焦点、展开状态。

桌面 Enter 发送，Shift+Enter 换行；输入法组合过程中不发送。手机 Enter 换行，通过发送按钮提交，不自动聚焦弹出键盘。

## 回答下方工具栏

按来源顺序提供复制、点赞、点踩、从此处创建新对话、用量、耗时、完成时刻；插件已有的备注、重新生成等能力可放入更多菜单。图标和 hover/focus/选中状态统一。

- 复制真实 Markdown 源文；代码块保留独立复制入口。
- 反馈使用官方 `messageFeedback`，服务端核验身份、会话归属、已完成消息和版本。刷新后读回真实状态；没有服务时明确不可用，不能用本地状态冒充保存。
- 分支使用官方 Agent/Session 的已完成回合前缀。校验边界、继承长度、所有权及正在执行状态；不会删除原对话或带入边界之后的消息。复用 kit 的 `conversationModel()` 恢复边界内的官方模型选择，不能用新的全局默认覆盖旧会话。
- 用量使用官方 `deriveTurnTokenUsage`，耗时来自真实事件时间；缺失数据应隐藏或写“未提供”，不估算成真实统计。详情可点击或键盘展开，不只靠 hover。
- 窄屏可隐藏工具文字，但保留图标、可访问名称、触摸命中区域和详情。

## 实施与验收

在已有插件中修改，不创建替代应用。可复制 `chat-base.css` 和所需公共资源，使各插件归档独立可用；不要引入对私有业务插件的运行依赖。记录公共基线来源，复制后核验文件一致性。将资源加入包 files、verifyFiles 和受保护的静态路由。

验证范围应覆盖：空态、真实或明确标注的模拟流式、长文上滚、思考折叠、最新行末尾在窄屏和缩放后真实可见、译文/原文切换与翻译失败重试、工具状态、停止、历史恢复、复制、反馈刷新、分支、统计详情、手机输入法和窄屏溢出。中文思考验收需检查实际句子使用的语言，不能因英文句子引用了中文就判定通过。带数据的功能不能仅凭截图验收；安全接口检查 owner 隔离、无效目标、并发版本和撤权。

按本次改动选择对应检查，不为仅更新说明重复运行真实模型或生产操作。译文补充纯文本、包装、旧缓存及代码保真；历史补充长标题与按钮触达；业务确认按工作流参考覆盖确认前不发布/删除/应用候选、重复点击、过期/换会话/版本冲突和超时回执。构建和独立归档消费只证明相应产物可用，CI 的 Linux、Windows、macOS × Node 22/24 共六组通过，也不能代替真实宿主、外部接口和页面验收。

用相同视口和同类消息状态对照封闭化代码渲染结果与新页面，检查字体、间距、颜色、图标、工具栏。桌面与手机分别截图，声明模拟与真实宿主/模型/正式环境证据的区别。过程材料按项目约定留在 `.local`，不要把私有截图或验收数据放入本 skill。
