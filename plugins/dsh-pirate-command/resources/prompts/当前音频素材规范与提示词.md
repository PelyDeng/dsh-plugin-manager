# 当前音频素材规范与提示词

更新：2026-09-10。本文用于向同事交接音频制作要求，是音频合同及复制用音频 TXT 的唯一编辑源。修改要求时先改本文，再导出 TXT；不要把图片规范中的透明度、画布或视觉风格后缀拼到音频提示词中。

项目说明、状态语义和协作规则以插件根 [AGENTS.md](../../AGENTS.md) 为准。实际选用文件、缺项和验收状态见 [资源清单](../资源清单.md)，替代关系见 [资源变更记录](../资源变更记录.md)。本文说明怎么制作，不记录每次生成和验收过程。

## 1. 当前有什么，仍缺什么

当前 [scene-audio.js](../../web/src/scene-audio.js) 使用 WebAudio 振荡器和滤波噪声合成海浪床及 15 种短音效。它们可以承担事件提示，但不是电影原曲、真实乐器录音、动物录音或真人角色配音。听感与完整电影配乐的差距仍需后续制作解决，不能把接入合成音效写成全部音频交付完成。

| 当前标识 | 合成声音与用途 | 当前实现的边界 |
| --- | --- | --- |
| 海浪床，无独立 cue 标识 | 低通噪声循环，缓慢调节音量 | 使用 2 秒噪声源，不是本规范要求的 20 秒海浪成品 |
| `creak` | 低频锯齿波滑音，模拟船板吱呀 | 环境短音，不是真实木船录音 |
| `gull` | 两段正弦滑音，模拟远处海鸥 | 环境短音，不是真实鸟鸣 |
| `horn` | 两个持续音，提示敌船入场 | 不含真实管乐或电影进攻号录音 |
| `dispatch` | 原创短旋律，提示实时分工 | 不是《He's a Pirate》前奏 |
| `drum` | 低频滑音加滤波噪声，工作时按阶段重复 | 单次鼓点，不是连续战鼓演奏成品 |
| `cannon` | 低频噪声与降调，配合炮口发射 | 一次发射短音 |
| `impact` | 短噪声与降调，配合炮弹命中 | 与落水分别触发 |
| `splash` | 两段滤波噪声，配合炮弹落水 | 不包含发射声或命中声 |
| `coin` | 两个高音，配合银币到达 | 当前不区分苹果纹和羽毛纹银币的音色 |
| `paper` | 两段带通噪声，配合卷轴落桌 | 模拟纸张展开 |
| `bottle` | 短促降调加清亮高音，配合稿瓶落桌 | 稿瓶等待确认时也可提示到达，不表示任务成功 |
| `aggregate` | 原创短旋律，提示整合阶段 | 不是完整整合配乐或电影高潮 |
| `victory` | 原创正弦短旋律，仅提示本轮完成 | 不是《He's a Pirate》八音盒成品 |
| `failure` | 原创下行短旋律，提示公开失败 | 不是真实低沉单簧管变奏 |
| `waiting` | 两个柔和提示音，提示等待或部分完成 | 不使用胜利语气 |

仍需交付的声音包括：更自然的海浪与船体细节、真实感更好的号角和战鼓、剑鸣与沙漏、猴子报警、船长叹气、角色语音，以及覆盖阶段转换的完整配乐和乐器质感。当前舞台采用卷轴与稿瓶；剑与沙漏是后续信物候选，有文件也不能直接声明已接入。

用户要求的《He's a Pirate》前奏、高潮和任务完成时的八音盒版本仍保留为待交付、待接入的成品要求。下方原创音乐提示词只用于制作独立候选，不替代这个缺项。

## 2. 每次交付一个可独立使用的声音

- 制作母版统一为 WAV、48 kHz、24-bit PCM。需要根据甲板位置设置声像的单次声音交 mono；音乐交 stereo。海浪先交 mono 循环床，由页面统一混合。工具原始输出不符合母版格式时保留原文件，另存转换版本，并记录原采样率和位深；转成 24-bit 不代表原始质量提高。
- 海浪床交 20 秒可无缝循环文件。音乐中的持续工作段也交 20 秒循环；入场、分工、整合、完成、失败及等待提示交独立短段。不要把整场海战的音乐、炮击、对白和海浪混成一个不可拆的文件。
- 单次音效保留完整起音和自然尾音，不截尾，不附一大段静音。鼓点、银币、纸张、瓶塞等提示应短促，不能长时间盖住用户阅读和协作对话。具体时长以对应提示词为准。
- 保留调音余量，建议母版峰值不高于 -3 dBFS；不得削波、爆音或为了响度过度压缩。运行时再按类别设置音量，炮声和提示声不能通过文件本身异常放大来抢占注意。
- 循环文件标明循环起止采样点和总时长；48 kHz 的 20 秒文件应为每声道 960000 个采样，循环区间写为 `[0, 960000)`。接缝无点击声，节奏与尾音能连续衔接，不能仅靠文件名写 `loop` 判定通过。
- 每个文件附实际来源或制作工具、模型或版本（未知写未知）、实际提示词、使用的参考版本、声道、采样率、位深、时长、循环点和原文件哈希。成品曲目还要给出具体录音或编曲版本及可用来源；不只写曲名。

原始输出放入 `resources/sources/audio/`；格式转换、裁切或调音版本放入 `resources/processed/audio/`；试听与检查文件放入 `resources/previews/audio/`。按音效类别及版本分目录，原始输出保留字节。处理和验收记录放入 `resources/tools/` 对应音频目录。只有明确选用的文件才进入运行时素材目录，预览混音不作为单项运行时音效。

## 3. 声音和任务状态的关系

页面默认静音，由用户开启；开启失败应显示实际状态。再次开启只恢复当前氛围，不补播静音期间的派单、失败或胜利提示。历史恢复和切换协作直接恢复当前状态，不重放旧任务的一次性声音。

正在执行、局部失败、等待用户、部分完成和整轮完成分别处理。一名船员等待或失败时，其他船员可能仍在执行，不能只凭最新一条事件停止全部工作氛围。等待、部分完成不播放胜利段；只有后端明确整轮完成才播放完成提示。音效不能决定业务状态。

派单、银币到达、信物落桌、炮口发射及命中或落水分别触发。信物返回只说明该公开事件到达；等待确认的稿瓶不代表成功。正常终态允许已有炮弹有限收尾，停止则清理旧任务声音和在途效果。海浪床与少量环境细节可以继续，轮询不得反复触发木板或海鸥短音。

## 4. 复制用制作提示词

以下 6 项分别导出音频 TXT，和图片素材分开计数。含 `[CUE]` 的模板必须在提交前替换成一个允许值，一次只生成这一种声音；不能保留占位符、把多个值连写或要求工具输出整套混音。英文提示词提出目标，实际文件格式、接缝和听感仍需检查。

### 海浪循环床

<!-- asset: audio-ambient-sea -->

```text
Create one original ocean ambience asset for a pirate ship game scene: gentle open-sea water rolling alongside a slowly sailing wooden vessel. Deliver exactly 20 seconds of seamless looping water, mono WAV, 48 kHz, 24-bit PCM. Keep it soft and even, with small natural swells and no dramatic wave crashes. Include no creaking, birds, voices, wind gusts, music, weapons, or interface sounds. The entire file must loop cleanly at sample range [0, 960000), without a click, abrupt swell, or audible fade seam. Keep peak level below -3 dBFS, preserve headroom, and do not clip. Provide the actual duration, format, loop points, and source or generation version with the asset.
```

### 木船与海鸥细节

允许值：`wood_creak`、`distant_gull`。每次任选一个替换 `[CUE]`。

<!-- asset: audio-ambient-details -->

```text
Create exactly one isolated environmental sound: [CUE]. The only allowed selection is wood_creak OR distant_gull; choose one before generation. For wood_creak, make one quiet, organic wooden hull creak lasting 0.6 to 1.5 seconds. For distant_gull, make one soft, distant seabird call lasting 0.5 to 1.5 seconds. Keep a natural onset and complete decay. Deliver mono WAV, 48 kHz, 24-bit PCM, with peak level below -3 dBFS. No music, sea bed, speech, other animals, repeated sequence, stereo panning, or baked scene mix. Avoid harsh piercing frequencies and long silence. Report the actual sound selection, duration, source, and version.
```

### 战斗声音

允许值：`horn`、`drum`、`cannon`、`impact`、`splash`。发射、命中、落水分别制作。

<!-- asset: audio-battle-cues -->

```text
Create exactly one isolated pirate battle sound: [CUE]. Select only horn, drum, cannon, impact, OR splash before generation. Horn means one low distant naval horn, 1 to 2 seconds. Drum means one resonant war-drum hit, 0.2 to 0.6 seconds, suitable for runtime repetition. Cannon means one wooden-ship cannon discharge with its own short tail, 0.6 to 1.5 seconds. Impact means one cannonball striking wooden planks, 0.3 to 1 second. Splash means one cannonball hitting open water, 0.5 to 1.5 seconds. Preserve the complete decay. Deliver mono WAV, 48 kHz, 24-bit PCM, peak below -3 dBFS. Include no additional action, music, dialogue, ambience, rhythm loop, or panning. Report the selected action, actual duration, source, and version.
```

### 银币与信物

允许值：`coin`、`paper`、`bottle`、`sword`、`hourglass`。剑与沙漏制作后仍作为候选，按实际角色及道具接入。

<!-- asset: audio-token-cues -->

```text
Create exactly one short pirate token sound: [CUE]. Select only coin, paper, bottle, sword, OR hourglass before generation. Coin is one light silver-coin chime. Paper is one small parchment scroll opening. Bottle is one gentle cork pop from a glass message bottle. Sword is one brief clean blade ring. Hourglass is one small glass hourglass being turned with a subtle sand movement. Make the chosen action distinct but restrained, 0.2 to 1 second including its natural tail. Deliver mono WAV, 48 kHz, 24-bit PCM, peak below -3 dBFS. No music, voices, sea ambience, additional object sounds, repeated pattern, panning, or long silence. Report the selection, actual duration, source, and version.
```

### 原创阶段音乐候选

允许值：`idle_sailing`、`dispatch`、`working`、`aggregation`、`victory_musicbox`、`failure_low_clarinet`、`waiting_neutral`、`partial_neutral`。这份模板生成原创候选；电影原曲与其八音盒编曲成品按第 5 节另行交付。

<!-- asset: audio-scene-music -->

```text
Compose one original instrumental pirate game music asset for [CUE]. Select exactly one: idle_sailing, dispatch, working, aggregation, victory_musicbox, failure_low_clarinet, waiting_neutral, OR partial_neutral. Use an original theme and keep this deliverable separate from any named film recording. Idle_sailing and working must be seamless 20-second loops: gentle sailing for idle, restrained rhythmic tension for working. Other selections are 2 to 5-second standalone cues with complete endings. Dispatch signals departure; aggregation builds focused anticipation; victory_musicbox resolves warmly with music-box timbre; failure_low_clarinet gives a subdued descending clarinet response. Waiting_neutral and partial_neutral remain unresolved and never sound victorious. Deliver stereo WAV, 48 kHz, 24-bit PCM, peak below -3 dBFS. No dialogue, animal calls, weapon effects, ocean bed, or combined stage medley. Report the selection, tempo, actual duration, loop points when applicable, source, and version.
```

### 猴子与船长反应

允许值：`monkey_alarm`、`captain_sigh`。均为独立非语言反应；角色对白、台词录制需要另给具体公开文本，不混在本模板中。

<!-- asset: audio-character-reactions -->

```text
Create exactly one nonverbal character reaction: [CUE]. Select monkey_alarm OR captain_sigh before generation. Monkey_alarm is a small expressive monkey giving a brief startled alarm, 0.5 to 1.2 seconds, playful rather than painfully shrill. Captain_sigh is one natural adult male sigh of disappointment, 0.6 to 1.5 seconds, warm and restrained for a friendly chibi pirate captain. Preserve the complete breath or animal-call tail. Deliver mono WAV, 48 kHz, 24-bit PCM, peak below -3 dBFS. No spoken words, named actor imitation, music, coconut impacts, object effects, crowd sounds, ambience, repetition, or panning. Report the selected reaction, actual duration, source, performer or generation method, and version.
```

## 5. 电影配乐成品交接

《He's a Pirate》相关要求不通过上述原创模板冒充完成。交付者需提供实际可用的音频文件、来源、录音或编曲版本、起止时间与时长；八音盒版必须写明其具体编曲版本，不能只把合成器改成清亮音色就沿用原曲名称。原始文件完整保留，场景使用的裁切或循环版另存并记录处理。

| 成品用途 | 需要提供的内容 | 当前状态 |
| --- | --- | --- |
| 分发任务 | 《He's a Pirate》所选版本的前奏段，标明具体入点与出点 | 待交付、待接入 |
| 最终整合 | 所选版本的高潮段；爆炸与胜利号角另交单项，运行时混合 | 待交付、待接入 |
| 任务完成 | 具体八音盒编曲版本及适合淡出的片段 | 待交付、待接入 |
| 失败气氛 | 低沉单簧管变奏成品及其实际曲目或编曲说明 | 待交付、待接入；当前仅有原创合成短提示 |
| 角色语音 | 对应角色、实际公开台词、表演方式、版本与来源的独立语音文件 | 真人配音及完整角色语音尚未交付 |

## 6. 采纳前检查

先检查原文件与处理后文件的格式、声道、采样、峰值和时长，再实际试听单项及页面中的小音量混合效果。波形不为空只说明生成了信号，不能代替听感验收。海浪和音乐循环至少连续播放三轮，确认接缝、节拍和尾音；单次提示确认没有截尾、刺耳高频或多余事件。

页面检查包括默认静音、开启失败、静音与再次开启、历史恢复、停止、一个船员等待而另一个继续工作、局部失败、部分完成及整轮完成。核对音效是否来自当前公开事件，且与视觉动作和实际状态一致。采纳后同步资源清单、变更记录及受影响规则；候选、合成预览、已验收运行时成品分别标记。
