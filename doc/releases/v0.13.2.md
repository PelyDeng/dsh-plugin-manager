# DSH Plugin Manager 0.13.2

本次公共发布包含统一框架版本管理：根 `package.json` 的 `version` 是唯一版本源，manager、kit、auth、example 同步使用 0.13.2，定制插件继续独立版本。执行 `node scripts/version.mjs set X.Y.Z` 一次更新四个包和当前版本文档；文档模板通过 `{{FRAMEWORK_VERSION}}` 引用总版本，生成的 Markdown 随源码提交。使用方式见[版本管理](../versioning.md)。

自动检查覆盖 Windows、macOS、Linux 与 Node.js 22、24 六组组合，校验版本、文档同步及实际归档版本。Release 标签必须匹配框架版本；交付附件为 manager、kit 的 tgz、公共 auth/example 应用 ZIP 及 `SHA256SUMS.txt`。宿主继续使用 gitlink 锁定的版本，第三方依赖、数据格式及定制插件版本不随框架版本改写。

源码部署在镜像和插件归档准备完成后，停止旧服务并核验容器身份及持久挂载，随后直接安装并等待健康检查。各步骤继续显示实时与最终耗时。

`--resume` 沿用同一次发布的镜像、插件归档和原始输入，兼容旧版本未完成的发布记录。停服核验失败时尝试恢复旧服务，下次继续时重新核验；安装失败时保留现场。已有运行文件和历史操作目录保持原样。

部署指南、FAQ、配置模板及管理器说明同步描述当前流程。manager、kit、auth、example 统一使用 0.13.2，定制插件版本不变。
