# 0.15.0

框架升级到官方 DeepSeek Harness `0.1.5-alpha.2`，锁定提交 `b2e3b2a0125854567a4a5fcba75782e42fe84901`。manager、kit、auth 和 example 统一为 `0.15.0`。

kit 适配 `SessionHandle.read()` 的 `{ events, eventState }` 返回值，example 复用公共读取入口，修复 Agent 关闭后历史读取失败的问题。模型切换在异步校验后的写入边界重新检查权限，撤权后不会记录选择或更改默认模型。

example 使用官方实时流和持久化 message/attempt 流，保留中断输出、历史思考与首 token 时间，删除旧 `assistant/chunk` 接入。开发依赖与当前宿主一致，独立构建显式安装反馈类型所需的依赖。

源码准备在构建结束后核对宿主提交与包管理器，避免并行切换检出后误认构建结果。真实宿主测试失败时保存私有诊断日志。

部署前阅读[宿主兼容说明](../host-compatibility.md)。Session V3 迁移会改变事件序号；旧数据需按官方持久化语义读取，生产切换前应停止写入并备份。固定宿主镜像必须单独更新，旧宿主的按需构建基线不能复用。
