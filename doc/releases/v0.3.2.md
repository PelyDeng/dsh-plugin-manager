# DSH Plugin Manager v0.3.2

把 DeepSeek Harness 插件交付成团队可使用的应用：统一登录、应用授权、独立打包与部署。本项目由社区独立维护，并非 DeepSeek 官方发布。

## 本版内容

- 管理器 0.3.2：独立插件打包、可移植发布物组合、显式 root 配置和受控生命周期。
- kit 0.1.1：可选身份/授权接入，网页与 CLI 共用的默认 DeepSeek 凭据操作。
- auth 0.9.0：账号、应用授权和管理员“模型设置”；仅返回配置状态和 SHA-256 指纹，更换后后续请求无需重启。
- example 0.3.3：开发者快捷答疑、流式对话、个人历史；同步首次认证及模型配置 FAQ。
- 中英文项目介绍、公共界面导览和首次部署说明。

[Linux Docker 部署](https://github.com/PelyDeng/dsh-plugin-manager/blob/main/doc/first-deployment.md)是完整源码站点入口；[发布物交付](https://github.com/PelyDeng/dsh-plugin-manager/blob/main/packages/plugin-manager/DELIVERY.md)适用于已有兼容官方宿主的部署者。GitHub 自动生成的 Source code ZIP 不带子模块源码；完整源码部署应递归克隆。

工具包名称不表示已经发布到 npm。应用 ZIP 不包含官方宿主、依赖缓存、容器镜像或任何运行数据，不是离线安装包。请保留旧数据、配置、发布清单和备份，按指南更新。

## 宿主与使用要求

此版本的源码宿主为 DeepSeek Harness `d347e703908d0406b7a7ef80e3a0e594d86b2215`（源码版本 `0.1.3-alpha.1`）。源码部署使用仓库提供的子模块；源码版本号不代表同名 npm 包已发布。默认密钥管理依赖官方 credentials 服务和 credentials-local 存储。使用其他宿主时，按插件接口与运行依赖确认兼容性。

“密钥已配置”表示凭据已保存；实际问答仍需要可用的模型、余额与网络。应用认证与官方控制台认证独立。问题请见 [FAQ](https://github.com/PelyDeng/dsh-plugin-manager/blob/main/doc/FAQ.md) 或提交脱敏的 [Issue](https://github.com/PelyDeng/dsh-plugin-manager/issues)。
