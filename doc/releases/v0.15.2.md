# DSH Plugin Manager 0.15.2

本版将公共框架升级到 DeepSeek Harness `0.1.5-alpha.2`，并包含自上个公共 Release `0.14.3` 以来的模型选择、按需构建和会话兼容修复。manager、kit、auth、example 统一为 `0.15.2`。

## 主要更新

- 对话输入框可以选择官方模型，新会话可沿用默认模型，历史会话和分支保留原有选择。异步校验后再次检查权限，避免撤权后继续记录选择或修改默认模型。
- 支持仅重建指定插件并复用经过校验的其他插件归档；兼容固定宿主镜像及插件目录内已纳入 Git 的常规 vendor 归档。宿主身份或共享输入不匹配时拒绝复用。
- 适配官方 Session 历史读取结果和实时、持久化 message/attempt 流，保留中断输出、历史思考及首 token 时间。
- 提供旧反馈迁移和官方 codec 会话快照校验入口，保留评分、备注、版本和时间戳；迁移工具先生成隔离结果，原数据由运维流程备份和切换。
- example 源码读取超过 100 行时自动分页并返回 `nextLine`；更新随包知识，用实际应用解释框架的分层与使用方式。
- 历史栏销毁时同步关闭重命名、删除和导出窗口，避免退出或权限变化后残留内容。
- 宿主冷启动验证保留完整的 60 秒等待窗口，不因连接立即被拒绝而在约 10 秒时提前终止；失败时保留输入，可通过 `--resume` 恢复。

## 安装与升级

Release 附件包含 `plugin-manager-0.15.2.tgz`、`plugin-kit-0.15.2.tgz`、公共 auth/example 应用 ZIP 和 `SHA256SUMS.txt`。安装前核对下载文件的 SHA-256。归档不包含官方宿主源码、凭据、运行数据或私有业务插件；这次发布不代表 npm 包或服务器已经更新。

使用方式见[上手指南](https://github.com/PelyDeng/dsh-plugin-manager/blob/v0.15.2/doc/getting-started.md)与[首次部署](https://github.com/PelyDeng/dsh-plugin-manager/blob/v0.15.2/doc/first-deployment.md)。

官方宿主锁定提交 `b2e3b2a0125854567a4a5fcba75782e42fe84901`（`0.1.5-alpha.2`）。从 0.14 系列升级前，请阅读[宿主兼容说明](https://github.com/PelyDeng/dsh-plugin-manager/blob/v0.15.2/doc/host-compatibility.md)：Session V3 迁移会改变事件序号，生产切换前需要停止写入并备份，旧反馈需显式迁移。固定宿主镜像须单独更新，不能复用旧宿主的按需构建基线。从 `0.15.0` 或 `0.15.1` 升级不需要再次迁移 Session 日志。
